RENDER SETUP - PLAYTALK AUTH (Node.js + PostgreSQL)

1) Variáveis de ambiente (Render > Service > Environment)
   - DATABASE_URL
     * Copie da instância de PostgreSQL criada no Render (Internal Database URL).
   - JWT_SECRET
     * Gere um segredo forte (ex: openssl rand -hex 32).
   - JWT_EXPIRES_IN (opcional)
     * Ex: 7d (padrão do código).
   - BCRYPT_SALT_ROUNDS (opcional)
     * Ex: 12 (padrão do código).
   - PGSSL (opcional)
     * Use "false" apenas se seu PostgreSQL não exigir SSL.

2) Como criar o PostgreSQL no Render
   - Crie um novo serviço "PostgreSQL" no painel do Render.
   - Após criado, copie a "Internal Database URL" e coloque em DATABASE_URL.
   - O Node.js se conecta usando essa URL.

3) Como criar a tabela users (migração)
   - Localmente (ou em um job no Render), rode:
     npm run db:migrate
   - Esse comando cria a extensão pgcrypto (para UUID) e a tabela users com:
     id, email, password_hash, progress, created_at.

4) Como iniciar o servidor após o deploy
   - O Render executará automaticamente o comando:
     npm start
   - O servidor sobe em PORT (definido pelo Render) e expõe:
     POST /auth/register
     POST /auth/login
     GET /auth/me (com JWT)

5) Endpoints principais
   - POST /auth/register
     Body JSON: { "email": "user@exemplo.com", "password": "senha forte" }
   - POST /auth/login
     Body JSON: { "email": "user@exemplo.com", "password": "senha forte" }
   - GET /auth/me
     Header: Authorization: Bearer <token>

Observação:
- Senhas nunca são retornadas nas respostas.
- O campo progress já está pronto para expansão futura (ex: progresso do usuário).
