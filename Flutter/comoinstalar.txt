Como instalar esta tela de login no seu projeto Flutter

1) Copie a pasta "Flutter/lib" deste repositório para a pasta "lib" do seu projeto.
   - Arquivo principal: lib/main.dart
   - Tela: lib/login_screen.dart

2) Se você já tem um main.dart no seu projeto e não quer substituir:
   - Mantenha apenas o arquivo login_screen.dart
   - No seu main.dart atual, importe e use a tela:

     import 'login_screen.dart';

     home: const LoginScreen(),

3) No terminal, dentro do projeto Flutter, rode:
   flutter pub get

4) Execute o app:
   flutter run

5) Próximo passo recomendado:
   - Trocar o método _submit() por chamada real da sua API de login.
   - Salvar token com flutter_secure_storage.
   - Redirecionar para a tela inicial após sucesso.
